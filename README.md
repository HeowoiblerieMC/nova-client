## About Nova Client

Nova Client is a lightweight 3D voxel sandbox that runs directly in a modern web browser.

The project combines a Minecraft-inspired block world with an original dark green visual identity. It is built using HTML, CSS, JavaScript, and Three.js without requiring installation or a dedicated game launcher.

The current version includes procedural terrain, block interaction, first-person controls, pixel-style textures, dynamic lighting, trees, clouds, and a custom Nova-themed interface.

> Nova Client is currently in Alpha. Features, visuals, performance, and world generation may change during development.

## Play Online

Nova Client can be played directly through GitHub Pages.

### [Launch Nova Client](https://heowoibleriemc.github.io/nova-client/)

For the best experience:

- Use Google Chrome, Microsoft Edge, or Mozilla Firefox
- Enable hardware acceleration
- Use a keyboard and mouse
- Play in fullscreen mode
- Avoid opening many GPU-intensive browser tabs

## Controls

| Action | Control |
|:---|:---:|
| Move forward | `W` |
| Move backward | `S` |
| Move left | `A` |
| Move right | `D` |
| Jump | `Space` |
| Sprint | `Shift` |
| Look around | `Mouse` |
| Break block | `Left Click` |
| Place block | `Right Click` |
| Select block | `1` to `5` |
| Change selected block | `Mouse Wheel` |
| Pause game | `Escape` |
